## 1. 这是什么

一个 Windows 桌面版的 2048 小游戏：4×4 的棋盘，通过滑动合并相同数字，目标合成 **2048**。

- 单文件绿色版，双击即可玩，**不需要安装**、不需要联网、不需要 Python。
- 支持键盘操作，自动保存最高分。

---

## 2. 开始游戏

### 2.1 用 exe（推荐）

1. 双击 `2048.exe`（首次启动约 1～3 秒，请稍候）。
2. 窗口打开即进入新的一局，直接操作即可，无需点「开始」。

> 若双击没有反应：先看是否被 Windows 拦截（第 6.1 节）；一次启动后建议把 exe 和同名文件放在同一个文件夹内，不要只拷贝 exe 的部分文件（这是 onedir 版本的说明，onefile 版本只有一个文件）。

### 2.2 用源码（开发者）

```powershell
pip install pygame
python main.py
```

需要 Python 3.10+ 与 pygame 2.5+，详见《04-开发规范与环境搭建》。

## 3. 界面说明

```
┌──────────────────────────────────────────┐
│  2048              分数 1024              │  ← 左：标题；右：本局分数 / 最高分
│                    最高 20480             │
│  ┌────────────────────────────────────┐  │
│  │         4×4 棋盘                    │  │  ← 方块在这里滑动合并
│  └────────────────────────────────────┘  │
│  [ 新游戏 ]    方向键 / WASD 操作          │  ← 重开按钮与操作提示
└──────────────────────────────────────────┘
```

- **分数**：本局累计得分，每次合并都会增加。
- **最高分**：历史最好成绩，关闭游戏后仍会保留。

---

## 4. 操作方法

| 按键 | 作用 |
| --- | --- |
| ↑ / W | 全部方块向上滑动 |
| ↓ / S | 全部方块向下滑动 |
| ← / A | 全部方块向左滑动 |
| → / D | 全部方块向右滑动 |
| R | 立即重开一局 |
| U | 撤销上一步 |
| ESC | 不退出游戏；通关提示时按 ESC 等于「继续挑战」 |

也可以用鼠标点击界面上的「新游戏」按钮。

**基本思路**：一次只往一个方向推，尽量让数字从小到大排成一条「蛇形」链，把大数字压在角落（通常是左下或右下），保持至少一行可活动的空间。

---

## 5. 规则与计分

1. 每次有效滑动后，棋盘空闲处会**随机出现一个新方块**（90% 是 2，10% 是 4）。
2. 两个**相邻且相同**的方块会合并成一个，数值翻倍；合并得分等于合并后的数值。
3. **每个方块一次移动中只能合并一次**：
   - `2 2 2 2` 向左 → `4 4`（得 8 分）
   - `4 4 8 8` 向左 → `8 16`（得 24 分）
4. 布局没有任何变化的按键视为**无效操作**：不生成新块、不加分。
5. 合出 **2048** 即通关，可继续挑战 4096、8192……
6. 棋盘填满且任何方向都无法再合并时，游戏结束。

## 6. 常见问题

### 6.1 双击后 Windows 提示「已保护你的电脑」/ 被浏览器或杀软拦截

这是无数字签名程序常见的 SmartScreen 提示，不代表文件有毒。处理方式：

- 浏览器下载被拦：在下载记录中右键文件 →「保留」/「仍要保留」。
- SmartScreen：点「更多信息」→「仍要运行」。
- 企业杀软拦截：把 exe 加入信任目录，或联系管理员；也可改用解压包（onedir）版本。

### 6.2 启动有几秒延迟

onefile 版本每次启动都会先解压自身，属于正常现象。介意可让发布方提供文件夹版（onedir），启动会明显更快。

### 6.3 文字变成方块或问号

说明字体资源缺失。请确认使用的是完整发布包（含 `assets`）；onedir 版本请勿单独拷贝 exe。

### 6.4 最高分突然归零

最高分保存在 `%APPDATA%\2048Desktop\save.json`。如果你清理过系统临时文件、换过 Windows 用户账户，或手动删除了该文件，纪录会重置。这是本机存档，不随 exe 文件走。

### 6.5 窗口里按方向键没反应

确认窗口处于激活状态（点一下窗口再操作）。若在「通关」或「游戏结束」提示界面，需先选择「继续挑战」或「再来一局」。

### 6.6 撤销不生效

只在游戏进行中可用，且只能撤销最近一步；游戏结束状态下不可撤销。

## 7. 卸载与清理

本程序不写注册表、不装服务：

1. 删除 `2048.exe`（或整个程序文件夹）。
2. 如需清空纪录，删除 `%APPDATA%\2048Desktop\` 文件夹。

---

## 8. 反馈问题时请提供

- 使用的版本（exe 属性页「详细信息」中的版本号）
- Windows 版本与屏幕缩放比例
- 问题现象与复现步骤
- 若是崩溃，附 `%APPDATA%\2048Desktop\crash.log`（如果存在）
